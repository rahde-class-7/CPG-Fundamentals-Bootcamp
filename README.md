# CPG-Fundamentals-Bootcamp
Hands-on introduction to Linux, Git/GitHub, Bash, Python, and automation, focused on building foundational skills for cloud engineering, DevOps, software development, and IT operations.

## Overview

This repository contains hands-on exercises and projects designed to build foundational skills for cloud engineering, DevOps, software development, and IT operations.

The course focuses on learning how common technical tools work together in a real development environment. Rather than studying each technology in isolation, students progressively build a workflow using Linux, Git/GitHub, Bash, Python, and basic automation.

## Who This Repository Is For

This repository is designed for beginners who want to build a technical foundation before moving into areas such as.

- Cloud Engineering
- DevOps
- Site Reliability Engineering (SRE)
- Systems Administration
- IT Operations
- Software Development
- Infrastructure Automation

No advanced programming or cloud experience is required.
